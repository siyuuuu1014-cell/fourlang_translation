# 中文到乌兹别克语直接语义测试 v1

本测试集包含 110 条人工编写的中文真实场景测试句，以及对应的乌兹别克语参考译文。

- `test_inputs.jsonl`：只包含编号和中文输入，用于盲测。
- `gold.jsonl`：包含参考译文和必须保留的中文关键含义，用于测试后核对。
- 所有内容仅用于评测，禁止加入训练集、蒸馏数据或选模验证集。
- 参考答案不是唯一正确译法。只要模型输出完整保留 `key_meaning_zh` 中的语义，且乌兹别克语可理解，即可判为语义通过。
- 数字、否定、条件、人物关系、时间和方向出现实质错误时，应判为失败，不能因句子大意接近而忽略。

## 建议记录

每条输出标记为：

- `PASS`：意思完整正确，允许措辞不同或轻微不自然。
- `MINOR`：核心意思正确，但有不影响理解的小问题。
- `FAIL`：漏掉或改变关键含义，数字、否定、条件、实体出错，或无法理解。

这批参考译文由 AI 编写并经过一致性检查，但尚未取得乌兹别克语母语者认证，不应称为正式金标准或生产上线认证。
