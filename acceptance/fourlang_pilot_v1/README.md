# 四语言应用验收小样本 v1

状态：AI 编写场景草稿，尚未通过母语/双语人工审核，不是采集的真实用户数据。

## 内容与范围

- 中文、英文、乌兹别克文、俄文各 20 条，共 80 条源文。
- 每种语言含日常、出行、工作学习、售后各 5 条。每条翻译成其他三种语言，展开为 240 个任务，每方向 20 条。
- 四种语言分别编写，不是同一批中文句子的平行译本；但场景主题存在重叠，不能视为完全独立随机样本。
- 这是先前建议的 20 条/方向试点，**不是完整的 100～200 条/方向验收集**。场景是否符合实际业务仍需用户确认。
- 人名、安排、商品和金额等均为虚构场景内容，不描述真实订单或服务规则。
- 未运行 Exp1/Exp2；未填写任何模型成绩；未提供人工参考译文。

## 文件

- sources.jsonl：80 条源文，附中文关键含义提示、挑战标签和源文确认栏。
- source_review.md：便于阅读的完整源文清单。
- tasks.jsonl：240 个翻译任务及空白评分字段。
- review_form.md：240 行的人工记录表，可填两版输出与等级。
- manifest.json：文件哈希、数量与状态。

## 审核顺序

1. 先让对应语言使用者确认源文自然且无歧义；中文含义提示也仅是 AI 辅助说明，不是标准译文，不可当作判断的唯一依据。
2. 问题题目在模型测试前修订；保留原版并创建新版本。先定题，再看模型输出，避免按模型表现选题。
3. 正式运行前，在服务器上对训练集、KD池及已有评测集做精确和近重复检查。本包尚未做此检查，不能承诺零重叠。
4. 模型输入只取 src_text 和语言方向；不要输入 meaning_hint_zh、标签、评分规则或参考。多句原文作为一个整体翻译。
5. Exp1、Exp2 使用相同解码设置，记录实际模型路径/哈希、运行时间和配置。模型推理不在本包准备步骤执行。
6. 组织者将两版译文按题随机置换为 A/B，映射单独保管，再交双语审核者。review_form.md 是组织者记录表，本身不是已随机化的盲评表。
7. 先评译文再揭示模型名称。拿不准时记 UNJUDGEABLE，不能强行判通过。对争议或严重错误安排第二人复核。

## 评分

- DIRECT：含义完整准确、目标语言自然，可直接使用。
- EDIT：含义基本正确，仅需轻微措辞/格式修改；关键数字、实体和否定不能错。
- FAIL：实质错译、漏译、添加无依据内容、目标语言错误，或无法使用。
- UNJUDGEABLE：无法可靠判断，单独报告，不算通过。
- 错误类型可多选：omission / addition / mistranslation / number_unit / entity / negation / wrong_language / fluency / other。

按方向分别报告：总题数、有效已评数、未评/无法判断数、DIRECT 比例、DIRECT+EDIT 比例、FAIL 比例及严重错误例子。比例分母为 DIRECT+EDIT+FAIL，同时报告其覆盖率，不能隐藏未评题。不同目标语言不要直接比较 BLEU 高低。

20 条/方向只适合流程和故障初筛，不能据此证明正式上线安全；本包没有自动通过阈值。扩大到 100～200 条/方向时，应加入真实业务来源与审核过的自然文本，避免仅改人名数字扩充。

## 隔离与复用限制

本目录不接入训练配置；数据标记 ACCEPTANCE_ONLY_NOT_FOR_TRAINING。此标记是用途声明，不是已实现的全仓库防泄漏机制。请不要复制进训练集、KD生成池或训练时选模验证集。

如果根据本包反复调参/修复，应将它归类为开发诊断集，另留未使用的最终验收集；不能继续将它称为独立最终测试。暂不计算 BLEU/chrF：没有人工确认的参考译文。
